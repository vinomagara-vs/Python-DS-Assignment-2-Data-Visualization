# Python-DS-Assignment-2-Data-Visualization

Taxi services generate large volumes of trip data every day. This data contains valuable information about customer travel behavior, fare patterns, trip distances, payment methods, and borough-level trends. Raw datasets often contain missing values and inconsistencies, making data cleaning and analysis essential before deriving meaningful insights.

In this project, taxi trip data is cleaned, analyzed, and visualized using Python libraries such as Pandas, Matplotlib, and Seaborn. The objective is to uncover patterns, identify trends, and present insights through effective visualizations.

**objectives**
Perform data cleaning and preprocessing.
Handle missing values using appropriate techniques.
Explore fare, distance, and tip-related trends.
Analyze customer payment behavior.
Compare trip activity across pickup boroughs and zones.
Create meaningful visualizations to support data-driven insights.
**Technology used**
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook / Google Colab
**Data set features**
The dataset includes information such as:
Pickup Borough
Pickup Zone
Trip Distance
Fare Amount
Tip Amount
Total Amount
Payment Method
**Data cleaning task**
The following preprocessing steps were performed:
Identified missing values using isnull().
Filled numerical missing values using mean or median.
Filled categorical missing values using mode.
Verified data types and corrected inconsistencies.
Checked for duplicate records.
**Data Visualisation**
Matplotlib - Bar Charts, Pie Charts, Histograms, Box Plots
Seaborn- Count Plots, Box Plots, Heatmaps, Pair Plots
**Key Insights**
Identified the most frequently used payment methods.
Compared fare and tip distributions across boroughs.
Analyzed relationships between trip distance, fare, and tip amount.
Visualized borough-wise trip volumes.
Discovered patterns in customer payment and travel behavior.
**Outcomes**
Data cleaning and preprocessing with Pandas
Handling missing values and data quality issues
Exploratory Data Analysis (EDA)
Data visualization using Matplotlib and Seaborn
Extracting actionable insights from real-world datasets
**Conclusion**
This project demonstrates how Python-based data analysis tools can transform raw taxi trip data into meaningful insights. By cleaning data, exploring trends, and creating visualizations, valuable information about customer behavior, trip characteristics, and payment patterns can be uncovered to support operational improvements and decision-making.
